
# 🚀 OmniSpace – Spatial AR Operating System

## 📌 Project Overview

OmniSpace is an innovative web-based Spatial AR Operating System designed to provide a futuristic and interactive digital workspace. It includes floating glass panels, interactive application cards, 3D space, file management, settings, a live clock, and an AR camera preview.

## 🎯 Objectives

- Create a futuristic desktop interface.
- Provide interactive application navigation.
- Develop a responsive user experience.
- Integrate camera access for AR preview.
- Explore modern spatial computing concepts.

## ✨ Features

- 🖥️ Futuristic Spatial Desktop
- 💎 Floating Glass Panels
- 📱 Interactive App Cards
- 🌐 3D Space Interface
- 📁 My Files Section
- ⚙️ Settings Panel
- 🕒 Live Digital Clock

## ⚙️ Installation and Setup

1. Download or clone this repository.
2. Open the OmniSpace folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.
6. Explore the OmniSpace interface.
